# SARCA Website

Institutional website for SARCA, using the SARCA navy/gold identity and the supplied emblem.

The public landing page does not expose local-development URLs. The Passenger and Driver CTAs route to `/passageiro/` and `/motorista/`; those access pages open the official request to `geral@deligotriunfal.site` until the web apps have their own public domains.

This site is a buildless static page. Open `index.html` directly for a quick local preview, or serve the directory with any static web server.
