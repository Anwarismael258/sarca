# SARCA Website

Institutional website for SARCA, using the SARCA navy/gold identity and the supplied emblem.

The public landing page does not expose local-development URLs. Until the web apps have official public domains, the passenger and driver CTAs open a direct access request to `geral@deligotriunfal.site` instead of sending visitors to `localhost`.

This site is a buildless static page. Open `index.html` directly for a quick local preview, or serve the directory with any static web server.
