# SARCA Website

Institutional website for SARCA, using the SARCA navy/gold identity and the supplied emblem.

The public landing page does not expose local-development URLs or email CTAs. The Passenger and Driver buttons open the current SARCA Web Apps directly on `https://www.sarca.digital/passageiro/` and `https://www.sarca.digital/motorista/`.

This site is a buildless static page. Open `index.html` directly for a quick local preview, or serve the directory with any static web server.
